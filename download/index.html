Get OGR Slip2D.

OGR Slip2D is a pre-release in active development. Signed installers are not ready yet; today you install it from its public source code, which takes a few minutes with Python.

Available now

From source

Version 0.1.235, the same code the tests run on.

Planned

Installers

Signed installers for Windows, macOS and Linux, next on the roadmap.

§ 01 — Install

Install from source

You need Python 3.11 or newer and Git. pip installs every dependency — NumPy, SciPy, Shapely, PySide6 and the rest — into a virtual environment of its own.

In PowerShell or the command prompt:

git clone https://github.com/samuelsl27/OGR-Slip2D.git
cd OGR-Slip2D
python -m venv .venv
.venv\Scripts\activate
pip install -e .
ogr-slip2d

In Terminal:

git clone https://github.com/samuelsl27/OGR-Slip2D.git
cd OGR-Slip2D
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
ogr-slip2d

In a terminal:

git clone https://github.com/samuelsl27/OGR-Slip2D.git
cd OGR-Slip2D
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
ogr-slip2d

If the ogr-slip2d command is not found, python -m ogr_gui starts the same program. The program opens with an empty project; File → Load Demo Slope loads a sample model to try.

§ 02 — What you get

Three commands, one package.

The package is called ogr-slip2d. It installs the desktop program, a command-line interface and, with the [mcp] extra, the server for AI agents.

CommandWhat it startsLearn more
ogr-slip2dThe desktop program (modeller, interpretation, Python terminal)The interface
ogr-slip2d-cliCommand-line interface: inspect and compute .ogr projectsCLI reference
ogr-slip2d-mcpMCP server for AI agents (needs pip install -e ".[mcp]")Connect an agent
Update

Stay current

From the repository folder: git pull, then pip install -e . again to pick up any new dependency.

Extras

Optional parts

[mcp] adds the MCP server; [dev] the development tools. The program itself needs neither.

Changes

Every version, explained

§ 03 — Before you use it

Pre-release means pre-release.

OGR Slip2D is research software in active development. Its methods are validated against published cases and its suite runs thousands of tests, but it has no warranty of any kind: results must be checked against independent calculations before anything is based on them. A project is signed by a person, not by a program.

Found something wrong — or a slope whose factor of safety you know? Open an issue. A validation case is the most valuable contribution there is.
