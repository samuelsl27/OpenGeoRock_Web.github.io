Five programs, one open core.

OpenGeoRock grows one program at a time, starting with the analysis practitioners reach for most: two-dimensional slope stability. Every program shares the same Python core for geometry, materials and loads, and the same licence.

Category 01

Slope stability

Limit-equilibrium analysis of natural slopes, cuts, embankments, dams and open pits.

Available · pre-releaseOGR-01

OGR Slip2D

2D limit equilibrium with nine methods and seven searches, finite-element groundwater, probabilistic and sensitivity analysis, supports, seismic loading, Eurocode 7 and an MCP server for AI agents.

Source available · v0.1.235Explore →
PlannedOGR-04

OGR Slip3D

Extension of the limit-equilibrium engine to three-dimensional slip surfaces, for open-pit mines, landslides and complex terrain.

Planned
Category 02

Finite elements

Stresses, deformations and coupled flow. The finite-element kernel already ships inside OGR Slip2D, where it solves groundwater flow.

PlannedOGR-03

OGR FEM2D

Elastoplastic 2D finite elements for stresses, deformations and strength reduction in excavations, tunnels and embankments.

PlannedOGR-05

OGR FEM3D

A full 3D finite-element solver for rock and soil mechanics, with coupled groundwater flow on arbitrary geometries.

Category 03

Data

Consistent inputs for every program of the suite.

PlannedOGR-02

OGR Data

A curated, queryable database of soil and rock-mass properties, correlations and empirical charts. It is the next step on the OGR Slip2D roadmap, after installers and more validation cases.
