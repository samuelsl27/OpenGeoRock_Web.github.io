How to read it

A manual you can cite.

  • Chapters, sections, equations, figures and tables are numbered, so a reference such as Eq. (3.2.4) stays stable.
  • Every formula names its original scientific source, listed in the bibliography.
  • Boxes titled In OGR Slip2D say exactly what the program does — defaults, checks and limits — and link to the source file that does it.
  • Limitations the code itself declares are stated, not hidden.
  • Every page prints cleanly, and is available in Spanish.
