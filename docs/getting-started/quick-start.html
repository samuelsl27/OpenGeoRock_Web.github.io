1.2

Quick start: your first model

Describes OGR Slip2D 0.1.235

This tutorial builds the slope on the home page from an empty project: a 16 m slope with a mid-height bench, three soils and a water table, analysed with three methods. It takes about fifteen minutes and touches every step of a typical analysis. The model is also available ready-made: ej01-two-layer-slope.ogr.

1.2.1The problem#

All coordinates are in metres, with xxx to the right and yyy up. The ground falls from left to right: crest at y=34y = 34y=34, a 6 m wide bench at y=26y = 26y=26 and the toe at y=18y = 18y=18; both faces are inclined 1V:1.5H.

1.2.2Start a project and set it up#

  1. Start the program (ogr-slip2d). It opens with an empty project; if not, use File → New Project (Ctrl+N).
  2. Open Analysis → Project Settings… (Ctrl+J). On the General page keep metric units with stresses in kPa, and set the failure direction to left to right: the ground falls to the right.
  3. On the Methods page enable Bishop Simplified, Spencer and GLE / Morgenstern-Price, and set the number of slices to 30.

1.2.3Draw the boundaries#

Boundaries can be drawn with the mouse, but typing the coordinates is exact. With a drawing tool active, type each vertex in the Enter X,Y field at the right of the status bar and press Enter; finish the boundary with Enter on an empty field, or from the right-click menu.

  1. Boundaries → Add External Boundary (Ctrl+1): 0,0 · 100,0 · 100,18 · 66,18 · 54,26 · 48,26 · 36,34 · 0,34. The external boundary closes itself.
  2. Boundaries → Add Material Boundary (Ctrl+2): 0,24 · 57,24 — the contact between sand and clay, which ends on the lower face.
  3. Again for the clay–gravel contact: 0,12 · 100,12.
  4. Boundaries → Add Water Table (Ctrl+3): 0,28 · 45,25 · 60,19 · 70,16.5 · 100,16.
Water does nothing until it is assigned

A water table only produces pore pressure in the materials that use it. When you finish drawing it, the program offers to assign it; if you skip that step, do it later with Properties → Assign Water Surface….

1.2.4Define and assign the materials#

  1. Properties → Define Materials…: create the three materials of Table 1.2.1, with strength type Mohr-Coulomb and pore pressure from the water table.
  2. Properties → Assign Materials: pick a material and click inside its region; repeat for the three layers.
An unassigned region is not empty

A region nobody assigns takes the first material of the list. Check the colours on the canvas before computing; with DATA TIPS on in the status bar, hovering over a region shows its material.

1.2.5Choose the slip surfaces#

The default search is a grid of circle centres. Surfaces → Auto Grid places a grid above the slope sized from the geometry; Surfaces → Surface Options… shows the surface type (circular) and the search method (grid). For each centre, the program tries a set of radii between the shortest circle that reaches the slope and the longest that stays within the slope limits.

1.2.6Compute#

Analysis → Compute (Ctrl+T) runs the search for each enabled method in the background, with a progress dialog and a cancel button. When it finishes, the Results dock lists the lowest surfaces and the canvas draws them, with the critical one in red.

Not every circle the grid generates gives a valid result. For Bishop, of 1 859 circles, 185 could not be divided into slices, 181 had no converged factor of safety (error code −111) and 4 failed the m-α check of Section 3.3 (code −112), which leaves the 1 489 valid surfaces of the table. Analysis → Analysis Notes… says why, and the Interpret window counts them by error code.

1.2.7Interpret#

Analysis → Interpret opens the result in its own window: the grid of centres coloured by factor of safety, the critical surface, the ranked surfaces and, for any slice, its forces, stresses and pore pressure. Choose the method in the toolbar to compare Bishop, Spencer and GLE.

A few things worth checking on any analysis:

  • The minimum is not on the edge of the grid. If the critical centre sits on the border, enlarge the grid and compute again.
  • The methods agree. Large differences between Bishop and the rigorous methods point at unusual interslice forces — see Section 3.2.
  • The pore pressures are the ones intended. Query the slices below the water table and check their pore pressure against the head above them.

1.2.8Save and go further#

File → Save writes the model to a .ogr file — plain JSON that the program, the command line, the Python API and the MCP server all open. From here:
