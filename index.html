Geotechnical software you can read, check and talk to.

OpenGeoRock is an open-source suite for slope stability, groundwater and rock mechanics. Its first program, OGR Slip2D, combines nine limit-equilibrium methods, finite-element seepage and probabilistic analysis — and ships an official MCP server, so AI agents can build, run and read models.

§ 02 — OGR Slip2D

Everything a slope analysis needs, in the open.

A desktop program with a modeller, a result interpreter and an embedded Python terminal — built on a computation core you can read line by line, and checked against published reference cases.

Nine limit-equilibrium methods

Ordinary, Bishop, Janbu simplified and corrected, Spencer, Morgenstern–Price/GLE, Lowe–Karafiath and both Corps of Engineers methods.

Seven search algorithms

Grid, slope, auto-refine, block, path, simulated annealing and particle swarm, for circular and non-circular surfaces, with focus objects and optimisation.

Twenty-two strength models

Mohr–Coulomb, undrained profiles, Hoek–Brown, Barton–Bandis, power curve, SHANSEP, anisotropic models and user-defined functions.

Finite-element groundwater

Saturated, unsaturated and transient seepage on a conforming triangular mesh, with seepage faces and a factor of safety per stage.

Probabilistic and sensitivity analysis

Monte Carlo and Latin hypercube sampling over seven distributions, probability of failure, reliability index and sensitivity sweeps.

Loads, supports and design codes

Nine support types, distributed and line loads, pseudo-static seismic and Newmark displacement, tension cracks and Eurocode 7 partial factors.

§ 03 — Built for AI agents

Ask for a slope. Get a factor of safety.

OGR Slip2D ships an official Model Context Protocol server, developed in the same repository as the solver. Any MCP client — Claude, ChatGPT, the OpenAI Agents SDK, or a local model in LM Studio or Ollama — can open the program, build the geometry, run the analysis and read every slice, while you watch it happen in the window.

  • One of the first geotechnical programs with an official MCP server — and, to our knowledge (October 2026), the first open-source slope-stability program to ship one.
  • 74 tools that reach every modelling and analysis action in the program's menus.
  • Works on the open window: the same model and the same undo stack as you.
  • Runs on your machine: stdio for desktop clients, HTTP with a token, OAuth 2.1 for remote ones.
