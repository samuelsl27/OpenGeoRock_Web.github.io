1.1

Instalación

Describe OGR Slip2D 0.1.235

OGR Slip2D es un paquete de Python, ogr-slip2d. Hasta que se publiquen instaladores firmados, se instala desde su código fuente público en un entorno virtual. Esta página trata los requisitos, la instalación en sí, los extras opcionales y cómo comprobar que todo funciona.

1.1.1Requisitos#

  • Python 3.11 o posterior. Las ejecuciones de integración continua prueban la batería de tests con 3.11, 3.12 y 3.13.
  • Git, para clonar el repositorio (o descargarlo como ZIP desde GitHub).

Todo lo demás lo instala pip a partir de los metadatos del paquete: NumPy, SciPy, Shapely, pyclipper, ezdxf, h5py, Matplotlib, PySide6, QtAwesome, Typer, Rich, Pydantic y ReportLab.

1.1.2Instalación desde el código fuente#

Clona el repositorio, crea dentro de él un entorno virtual, actívalo e instala el paquete en modo editable:

git clone https://github.com/samuelsl27/OGR-Slip2D.git
cd OGR-Slip2D
python -m venv .venv
.venv\Scripts\activate            # Windows
source .venv/bin/activate         # macOS and Linux
pip install -e .

La instalación editable (-e) enlaza el paquete con la carpeta que clonaste, de modo que basta con git pull para actualizar el código. En macOS y en algunas distribuciones de Linux el intérprete se llama python3.

1.1.3Los tres comandos#

El programa se abre con un proyecto vacío. File → Load Demo Slope carga un pequeño modelo de ejemplo —un talud de 10 m de altura, 1V:1H, en arcilla limosa con un nivel freático—, que es una forma rápida de comprobar que el análisis funciona. La Sección 1.2 construye un modelo desde cero.

1.1.4Extras opcionales#

Se pueden combinar varios extras: pip install -e ".[mcp,dev]". Conectar un agente de IA se describe paso a paso en la página de IA y MCP.

1.1.5Ejecución de la batería de tests#

El proyecto usa su propio ejecutor de tests, tests/_runner.py; pytest no es necesario, y los módulos de tests no se pueden importar fuera del ejecutor. Los tests gráficos construyen widgets de Qt reales, así que necesitan la plataforma sin pantalla («offscreen») de Qt:

# Windows (PowerShell)
$env:QT_QPA_PLATFORM = "offscreen"; python tests/_runner.py
# macOS and Linux
QT_QPA_PLATFORM=offscreen python tests/_runner.py

La batería completa —5 265 tests en la versión 0.1.235— tarda aproximadamente media hora; el tiempo varía entre ejecuciones idénticas, así que tómalo como una comprobación de que la batería termina y no como una medición. Para trabajar en un área, ejecuta solo una parte:

python tests/_runner.py transient          # files whose name contains it
python tests/_runner.py -k erfc            # tests whose name contains it
python tests/_runner.py --list transient   # show the selection, run nothing
Nota

Un patrón que no coincide con nada termina con el código 2 en lugar de anunciar un éxito vacío, y una ejecución filtrada imprime una advertencia FILTERED RUN alrededor de sus totales: no es evidencia para una versión.

1.1.6Actualización y desinstalación#

Desde la carpeta del repositorio, con el entorno activo: git pull y, después, pip install -e . de nuevo para incorporar cualquier dependencia nueva. Para desinstalar, borra la carpeta clonada: el entorno virtual está dentro de ella.

1.1.7Idioma de la interfaz#

La interfaz está disponible en inglés y en español (File → Preferences… → Language). El programa arranca en inglés; en la versión 0.1.235 la elección de idioma no se conserva entre sesiones. Las capturas de pantalla de esta documentación muestran la interfaz en inglés.
