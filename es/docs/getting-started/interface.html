1.3

La interfaz

Describe OGR Slip2D 0.1.235

OGR Slip2D tiene una ventana en la que se dibuja, se configura y se calcula el modelo —el modelador— y ventanas aparte que presentan los resultados. Esta página recorre las partes del modelador, las convenciones para dibujar en el lienzo, las ventanas de resultados, las preferencias y los atajos de teclado. El resto de la guía del usuario sigue los menús de izquierda a derecha.

1.3.1La ventana principal#

El programa arranca con un proyecto vacío llamado Untitled; la barra de estado sugiere File → Load Demo Slope para partir, en su lugar, de un pequeño modelo de ejemplo. La barra de título muestra la versión y, una vez guardado o abierto el proyecto, el nombre de su archivo.

De arriba abajo, la ventana contiene:

  • La barra de menús, con todos los comandos del programa (Sección 1.3.2).
  • La barra de herramientas, con los comandos más usados en forma de botones (Sección 1.3.3).
  • El lienzo, donde se dibuja el modelo y se muestran los resultados del último análisis (Sección 1.3.4).
  • El panel Results, que enumera los factores de seguridad más bajos del último análisis, y el panel Terminal, una consola de Python integrada que permanece oculta hasta que se elige Window → Terminal (Sección 1.3.6).
  • La barra de estado, con mensajes a la izquierda y, a la derecha, las ayudas de dibujo, las coordenadas del cursor y un campo para introducir coordenadas (Sección 1.3.5).

1.3.2La barra de menús#

Los catorce menús siguen, a grandes rasgos, el orden en que se construye un modelo: primero la geometría, las cargas y los soportes, y después las superficies de rotura, las propiedades, el agua subterránea y la estadística.

Los comandos cuyas condiciones previas no se cumplen siguen en el menú, pero aparecen en gris, y su información emergente explica el motivo: Boundaries → Add Water Table cuando el modelo ya tiene un nivel freático, Boundaries → Add Drawdown Line mientras no esté activado un análisis de desembalse rápido, los comandos de rejilla del menú Surfaces si el método de búsqueda no usa una rejilla de centros, y los comandos de agua subterránea y de estadística hasta que se activa en Project Settings el análisis al que pertenecen.

Help → Help Topics (F1) muestra la dirección del repositorio del código fuente; esta documentación es el manual del usuario. Help → Check for Updates… muestra la versión instalada y dónde se publican las versiones; no contacta con ningún servidor.

Versión 0.1.235

File → Print… solo muestra un mensaje que indica que la impresión está prevista. Para imprimir la vista del modelo, usa File → Print Preview…, cuya ventana tiene su propio botón de impresión, o expórtala con File → Export Image…. Edit → Picture Format → Vector (SVG) se registra, pero no se utiliza: Edit → Copy Image siempre copia un mapa de bits del lienzo.

1.3.3La barra de herramientas#

La barra de herramientas está fija bajo la barra de menús. Sus botones repiten comandos de los menús, en trece grupos separados por una línea fina; al pasar el cursor sobre un botón se muestra su nombre.

1.3.4El lienzo#

El lienzo muestra la sección del modelo con el eje xxx hacia la derecha y el eje yyy hacia arriba, en la unidad de longitud del proyecto (metros, salvo que se elija otro sistema de unidades en la Sección 2.1.2). La posición del cursor se lee en la barra de estado.

  • Haz zoom con la rueda del ratón, centrado en el cursor, o con View → Zoom: Zoom All (F2), Zoom In (F5), Zoom Out (F4), Zoom Window (arrastrar un rectángulo) y Zoom Mouse (el clic izquierdo acerca y el derecho aleja).
  • Desplaza la vista arrastrando con el botón central del ratón en cualquier momento, arrastrando con Shift pulsada en la herramienta Select, o con View → Zoom → Pan (F10).
  • View → Grid (F7), View → Ruler y View → Grayscale activan o desactivan la rejilla de fondo, las reglas y una representación en escala de grises.
  • View → Display Options… (Ctrl+D) elige lo que se dibuja: cada tipo de contorno, los vértices de los contornos, el grosor de línea, la regla y la rejilla, las placas de los soportes, la malla de elementos finitos y su numeración, los valores de la rejilla de presiones de agua, los vectores de flujo, el agua embalsada y las condiciones de contorno.

Cada tipo de contorno tiene su propio color, y las superficies de agua llevan una letra en su punto medio: W en el nivel freático, P en una línea piezométrica y D en la línea de desembalse.

Dibujar en el lienzo#

Un comando de dibujo —Boundaries → Add External Boundary, por ejemplo— pone el lienzo en un modo de herramienta, y la barra de estado indica qué espera la herramienta. Las convenciones son las mismas para todos los contornos:

  • Haz clic para añadir un vértice. El punto se ajusta a los vértices, las líneas y la rejilla cuando las ayudas de dibujo están activadas (Forzado del cursor).
  • Teclea el vértice en su lugar: escribe x, y en el campo Enter X,Y: de la barra de estado y pulsa Enter. Se aceptan como separadores comas, espacios y puntos y comas (12.5, 3.2, 12.5 3.2, 12.5;3.2), con el punto como separador decimal.
  • Enter termina el dibujo en cuanto tiene dos vértices. El contorno externo y la ventana de Block Search son polígonos cerrados y se cierran automáticamente; cualquier otro contorno es una polilínea abierta. Un nuevo clic sobre el primer vértice también cierra el contorno externo.
  • El clic derecho durante el dibujo abre un menú con Done, Close Boundary (solo para el contorno externo y la ventana de Block Search), Undo last vertex, los interruptores Snap, Ortho y OSnap, Coordinate Table… —una tabla de los vértices dibujados hasta el momento, para corregirla o ampliarla tecleando— y Cancel.
  • Esc cancela el dibujo en curso y vuelve a la herramienta Select.

Las herramientas que marcan puntos funcionan del mismo modo, con un número fijo de clics: dos para una carga distribuida, un rectángulo de rejilla de búsqueda, un soporte (primero la cabeza y después la cola) o un patrón de soportes, y uno para una carga lineal. Algunos comandos piden, en cambio, las coordenadas tecleadas en un pequeño diálogo, como x,y x,y …: las herramientas de anotación del menú Tools, los objetos de foco y Add Surface (centre and radius)….

Con la herramienta Select, el clic derecho sobre un objeto abre su menú contextual. El objeto que hay bajo el cursor se elige en este orden: un vértice (Move Vertex, Insert Vertex (after), Edit Coordinates…, Delete Vertex), una carga (Modify…, Delete), un soporte (Properties…, Stretch, Modify Pattern…, Delete), un contorno (Move Boundary, Edit Coordinates…, Convert Boundary…, Delete Boundary, más algunos comandos propios de su tipo) y, en una parte vacía de una región, un menú para asignar un material a esa región. Boundaries → Selection Filter… (Ctrl+F) elige qué tipos de objeto se pueden seleccionar: contornos, vértices, materiales, soportes, cargas y superficies de rotura, todos activados por defecto.

Forzado del cursor#

Tres ayudas de dibujo se activan y se desactivan desde la barra de estado, desde el teclado o desde el menú del clic derecho durante el dibujo:

  • SNAP (F9, activado por defecto) atrae el cursor hacia los vértices próximos, hacia las líneas y hacia la rejilla. Un círculo marca un vértice, una cruz un punto de una línea y un punto un nodo de la rejilla.
  • ORTHO (F8, desactivado) fija el segmento que se está dibujando a la horizontal o a la vertical cuando está a pocos grados de cualquiera de las dos.
  • OSNAP (F3, desactivado) dibuja líneas de prolongación temporales a partir de los lados y los vértices de los contornos próximos; con SNAP activado, el cursor puede ajustarse a ellas.

View → Snap… fija las tolerancias de captura —en píxeles de pantalla, para que el forzado sea igual de cómodo con cualquier zoom (vértice 12 px, línea 10 px, nodo de rejilla 8 px, prolongación 8 px)—, la ventana angular de ORTHO (5°) y el modo de los datos al pasar el cursor, y tiene un botón Restore Defaults. La rejilla de forzado sigue el zoom: su espaciado es un número redondo (1, 2 o 5 veces una potencia de diez) de unos 60 píxeles en pantalla.

Versión 0.1.235

Los campos Grid spacing del diálogo Snap no tienen un efecto duradero: el lienzo los sustituye por el espaciado que depende del zoom en cuanto se mueve el cursor. El atajo Ctrl+Shift+S está asignado tanto a View → Snap… como a File → Save As…; usa los menús para cualquiera de los dos.

Deshacer y rehacer#

Edit → Undo (Ctrl+Z) y Edit → Redo (Ctrl+Y) recorren las ediciones de la geometría —añadir, borrar, mover, convertir y remodelar contornos y sus vértices— y el pintado de materiales en las regiones con Properties → Assign Materials. Las ediciones hechas en diálogos (materiales, cargas, soportes, ajustes) no están en la pila de deshacer: mientras el diálogo está abierto, la forma de volver atrás es Cancel. La pila se vacía cuando se crea o se abre un proyecto, o cuando este se sustituye por el talud de demostración.

1.3.5La barra de estado#

La parte izquierda de la barra de estado muestra mensajes: qué espera la herramienta activa, qué hizo el último comando y el factor de seguridad del último análisis. Un mensaje permanece unos segundos y lo sustituye el siguiente; la lista completa de notas de un análisis está en Analysis → Analysis Notes… (Sección 1.3.6). La parte derecha contiene los indicadores permanentes.

Datos al pasar el cursor#

Con DATA TIPS activado, al pasar el cursor sobre una región de material, un soporte o una carga con la herramienta Select se muestran sus propiedades, con sus unidades, como información emergente. El diálogo View → Snap… ofrece tres niveles: None, Minimum (solo la identidad: el nombre del material, el tipo de soporte, la magnitud de la carga) y Maximum (todas las propiedades, el valor por defecto). El interruptor de la barra de estado alterna entre Maximum y None.

1.3.6Paneles acoplables y otros paneles#

Panel Results. Tras Analysis → Compute (Ctrl+T), el panel de la parte inferior muestra, para el primero de los métodos activados, el número de superficies válidas y el factor de seguridad crítico, seguidos de una tabla con las 50 superficies de menor factor: orden, factor de seguridad, método, centro xxx, centro yyy y radio. La superficie crítica es la primera fila, resaltada. Con una norma de diseño activada, el rótulo dice Over-design factor (factor de sobredimensionamiento) en lugar de Critical FoS (Sección 2.11). Los resultados de los demás métodos están en la ventana Interpret.

Los paneles se pueden mover, hacer flotantes y cerrar. Un panel cerrado se recupera haciendo clic con el botón derecho en la barra de herramientas, que enumera la propia barra y los paneles, cada uno con una marca de verificación.

Versión 0.1.235

Al seleccionar una fila del panel Results todavía no se resalta su superficie en el lienzo; usa Analysis → Interpret para inspeccionar superficies concretas.

Panel Terminal. Window → Terminal (Ctrl+`) abre una consola de Python integrada que se ejecuta dentro del programa, con el modelo abierto como project, el lienzo como canvas, la ventana como mainwindow, NumPy como np y los paquetes ogr_core y ogr_slip2d; help_ogr() imprime unos ejemplos. Enter ejecuta la entrada, Shift+Enter inicia una línea nueva, Ctrl+↑ y Ctrl+↓ recorren el historial y Ctrl+L borra la consola. El código escrito ahí puede cambiar cualquier cosa del modelo; la automatización mediante scripts se describe en la Sección 2.12.

Notas del análisis. Un análisis puede producir varias notas: un método que no se pudo ejecutar, un ajuste que la búsqueda elegida no lee, una norma de diseño que convierte el resultado en un factor de sobredimensionamiento. La barra de estado muestra la primera, seguida de [+n more — Analysis > Analysis Notes]; Analysis → Analysis Notes… abre un panel con todas ellas, incluidas las notas de la última ejecución estadística.

Info Viewer. Analysis → Info Viewer (Ctrl+I) resume el modelo: el número de contornos, materiales, soportes y cargas, el rectángulo envolvente, el método de búsqueda y el autor.

Panel Assign Materials. Properties → Assign Materials abre un panel flotante con la lista de materiales; véase la Sección 2.3.3.

1.3.7La ventana Interpret#

Analysis → Interpret abre los resultados del último análisis en una ventana aparte cuyo título es OGR Slip2D — Interpret — seguido del nombre del proyecto. Su lienzo es de solo lectura, de modo que el modelo no se puede cambiar desde ella; puede haber varias ventanas Interpret abiertas a la vez, y cada una conserva los resultados con los que se abrió. File → Close (Ctrl+W) la cierra.

  • Paneles: la leyenda de colores (Legend) a la izquierda; Summary y Surfaces (las 100 superficies con menor factor de seguridad) a la derecha; Slice Data en la parte inferior. Window muestra u oculta los tres últimos y View → Show Legend el primero.
  • Selector de método: cuando se han calculado varios métodos, una lista desplegable en la parte superior cambia toda la ventana de uno a otro.
  • Vista previa al pasar el cursor: con una búsqueda de rejilla, al pasar el cursor sobre un centro de la rejilla se dibuja la superficie de menor factor de seguridad de ese centro y se indica su factor de seguridad en la barra de estado.

Sus menús son File (exportar la imagen o los datos de las superficies como CSV), Edit, View (zoom, leyenda, opciones de isolíneas y de leyenda), Data (qué superficies se dibujan —mínimo global, mínimo por centro o todas—, filtros, el factor de seguridad a lo largo del talud, exportaciones de datos, superficies no válidas, fuerzas de los soportes y retroanálisis), Query (consultas, dovelas, línea de empujes, valores a lo largo de la superficie, diagrama de sólido libre de una dovela, superficies que pasan por un punto, tabla de resultados), Groundwater, Statistics (gráficos de histograma, acumulado, dispersión, sensibilidad y convergencia), Tools, Window y Help. Los comandos que necesitan algo que el proyecto no tiene —un análisis transitorio, soportes, resultados estadísticos— aparecen en gris y su información emergente dice qué falta. Todo lo que contiene esta ventana se describe en la Sección 2.8.

Versión 0.1.235

Algunos comandos de la ventana Interpret todavía no hacen nada: View → Data Tips, los cuatro interruptores de visualización de la parte superior del menú Groundwater (Phreatic Surface, Piezometric Lines, Flow Vectors, Streamlines) y Tools → Measure y Tools → Dimension Length.

1.3.8Otras ventanas de resultados#

Interpret Groundwater (Groundwater → Interpret Groundwater, disponible una vez calculado un análisis de filtración por elementos finitos) muestra el campo de filtración sobre la malla: altura total HHH, altura de presión PPP o presión intersticial uuu, con interruptores para los vectores de flujo, la superficie libre (P=0P = 0P=0) y la malla, una herramienta Discharge section… para el caudal que atraviesa una sección y, en un análisis transitorio, un selector de etapa y un gráfico del factor de seguridad en función del tiempo. Véase la Sección 2.9.

Statistics (Statistics → Show Statistics, que se abre automáticamente tras Statistics → Compute Statistics) presenta una ejecución probabilística o de sensibilidad: el histograma del factor de seguridad con la probabilidad de rotura y el índice de fiabilidad, la convergencia de la media y de la probabilidad de rotura con el número de muestras, diagramas de dispersión frente a cada variable aleatoria y el gráfico de sensibilidad. Véase la Sección 2.10.

Groundwater → Drawdown Level Sweep… termina con un gráfico del factor de seguridad en función del nivel de desembalse, y Data → Support Force Diagram… en la ventana Interpret abre el diagrama de fuerzas de un soporte. Estos gráficos se abren en ventanas propias.

Varios proyectos a la vez#

Window → New Window abre un segundo modelador, independiente, con su propio proyecto. El menú Window enumera las ventanas abiertas, marca la activa con un punto y las que tienen cambios sin guardar con un asterisco, y trae cualquiera de ellas al primer plano; Window → Close Window cierra la actual.

Anotaciones#

El menú Tools dibuja sobre una capa de anotaciones aparte que el análisis nunca lee: líneas, flechas, polilíneas, polígonos, rectángulos, círculos y texto (Tools → Draw), cotas de longitud, de ángulo y horizontales o verticales (Tools → Dimensions y Tools → Measure), ejes y una imagen de fondo. Los puntos se teclean como coordenadas. Tools → Annotations las gestiona, las muestra, las oculta y las elimina. Tools → Convert Tool to Boundary… es la única manera de que una anotación pase a ser geometría del modelo: copia una línea, polilínea, polígono, rectángulo o círculo en un contorno externo, un contorno de material, un nivel freático, una línea piezométrica o una grieta de tracción, y conserva la anotación. Tools → Property Tables muestra tablas de solo lectura de los materiales, los soportes y las propiedades hidráulicas, con un botón para copiarlas al portapapeles.

1.3.9Preferencias#

File → Preferences… fija el idioma (English o Español) y el tema (Light o Dark) y los aplica con Save.

  • El tema cambia al instante.
  • El idioma se aplica a los diálogos y las ventanas que se abren después (incluida una ventana abierta con Window → New Window); los menús de las ventanas ya abiertas conservan su idioma.
  • Ninguna de las dos opciones se guarda: el programa siempre arranca en inglés con el tema claro.

Los nombres de los menús de esta documentación son los de la interfaz en inglés.

Versión 0.1.235

Las tres casillas de verificación del grupo inferior del diálogo Preferences —Show Tabs for Multiple Windows, Mark file as modified after importing y Default to compressed format when saving— todavía no están conectadas a nada.

1.3.10El puente para agentes#

Un agente de IA conectado mediante el servidor MCP puede trabajar sobre el modelo abierto en la ventana, donde cada edición se ve en el momento en que ocurre. Tools → Agent bridge (MCP) controla esta conexión. Se activa al arrancar el programa, salvo que este se arranque con ogr-slip2d --no-agent-bridge, y la barra de estado indica entonces el número de proceso y el puerto: Agent bridge on (pid …, port …).

  • El puente escucha solo en la máquina local (127.0.0.1) y exige un token aleatorio; el servidor del agente lo encuentra cuando se arranca con ogr-slip2d-mcp --attach.
  • Una edición hecha por el agente es un paso de Edit → Undo, y un análisis que ejecuta se muestra en el panel Results y en el lienzo, igual que al ejecutar Compute.
  • Mientras la ventana está calculando, se rechazan las ediciones del agente, para que el modelo no cambie durante el análisis.
  • Al desmarcar la entrada del menú se cierra el puente.

La configuración de un agente se describe en la página de IA y MCP y las herramientas que puede usar, en la Sección 5.1.
