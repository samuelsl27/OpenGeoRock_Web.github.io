Inicio/Descargar OGR Slip2D

Descargar OGR Slip2D.

OGR Slip2D es una versión preliminar en desarrollo activo. Los instaladores firmados aún no están listos; hoy se instala a partir de su código fuente público, lo que lleva unos minutos con Python.

Disponible ahora

Desde el código fuente

Versión 0.1.235, el mismo código sobre el que se ejecutan los tests.

Previsto

Instaladores

Instaladores firmados para Windows, macOS y Linux, los siguientes en la hoja de ruta.

§ 01 — Instalación

Instalación desde el código fuente

Necesitas Python 3.11 o posterior y Git. pip instala todas las dependencias —NumPy, SciPy, Shapely, PySide6 y el resto— en un entorno virtual propio.

En PowerShell o en el símbolo del sistema:

git clone https://github.com/samuelsl27/OGR-Slip2D.git
cd OGR-Slip2D
python -m venv .venv
.venv\Scripts\activate
pip install -e .
ogr-slip2d

En Terminal:

git clone https://github.com/samuelsl27/OGR-Slip2D.git
cd OGR-Slip2D
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
ogr-slip2d

En un terminal:

git clone https://github.com/samuelsl27/OGR-Slip2D.git
cd OGR-Slip2D
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
ogr-slip2d

Si no se encuentra el comando ogr-slip2d, python -m ogr_gui arranca el mismo programa. El programa se abre con un proyecto vacío; File → Load Demo Slope carga un modelo de ejemplo para probar.

§ 02 — Qué se obtiene

Tres comandos, un paquete.

El paquete se llama ogr-slip2d. Instala el programa de escritorio, una interfaz de línea de comandos y, con el extra [mcp], el servidor para agentes de IA.

ComandoQué arrancaMás información
ogr-slip2dEl programa de escritorio (modelador, interpretación, terminal de Python)La interfaz
ogr-slip2d-cliInterfaz de línea de comandos: inspeccionar y calcular proyectos .ogrReferencia de la CLI
ogr-slip2d-mcpServidor MCP para agentes de IA (requiere pip install -e ".[mcp]")Conectar un agente
Actualización

Mantenerse al día

Desde la carpeta del repositorio: git pull y, después, de nuevo pip install -e . para incorporar cualquier dependencia nueva.

Extras

Partes opcionales

[mcp] añade el servidor MCP; [dev], las herramientas de desarrollo. El programa en sí no necesita ninguno de los dos.

§ 03 — Antes de usarlo

Una versión preliminar es una versión preliminar.

OGR Slip2D es software de investigación en desarrollo activo. Sus métodos están validados con casos publicados y su batería de tests ejecuta miles de pruebas, pero no tiene garantía de ningún tipo: los resultados deben contrastarse con cálculos independientes antes de basar nada en ellos. Un proyecto lo firma una persona, no un programa.

¿Has encontrado algún error o conoces el factor de seguridad de un talud? Abre una incidencia. Un caso de validación es la contribución más valiosa que existe.
